# Эмулятор оболочки UNIX-подобной ОС

## Общее описание

Консольный эмулятор командной строки (CLI) на Python. Приглашение к вводу
строится из реальных данных ОС (`username@hostname:~$`). Эмулятор работает
как REPL: читает команду, выполняет её и выводит результат.

## Описание функций и настроек

### Команды

- Ввод делится на команду и аргументы по пробелам.
- `ls [аргументы]`, `cd [аргументы]` — заглушки: выводят имя и аргументы.
- `exit` — завершить работу эмулятора.
- Ошибки (неизвестная команда, неверные аргументы) выводятся в виде
  `команда: сообщение`.

### Параметры командной строки

- `--vfs ПУТЬ` — путь к физическому расположению VFS.
- `--script ПУТЬ` — путь к стартовому скрипту.

При запуске все параметры выводятся в формате `[debug] ключ = значение`.

### Стартовый скрипт

Одна команда на строку; пустые строки и строки, начинающиеся с `#`,
пропускаются. На экране виден и ввод, и вывод (как диалог). Скрипт
останавливается на первой ошибке: эмулятор сообщает номер строки и
завершается с кодом 1. Команда `exit` в скрипте завершает эмулятор.

## Сборка, запуск и тесты

Нужен Python 3.8+, сборка не требуется. Запуск из любого каталога:

    ./run.sh
    ./run.sh --script scripts/start_stage2.emu

Тесты (из корня репозитория):

    python3 -m unittest discover -s tests -t .

Скрипты ОС для проверки (запуск: `sh scripts/имя.sh`):

- `params_*.sh` — все параметры командной строки;

## Примеры использования

    user@host:~$ ls -l /tmp
    ls ['-l', '/tmp']
    user@host:~$ cd a b
    cd: too many arguments
    user@host:~$ foo
    foo: command not found
    user@host:~$ exit
